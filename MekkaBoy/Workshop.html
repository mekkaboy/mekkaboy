Workshop

Turns a game ROM you own into a MekkaBoy cartridge. It runs in your browser. The file is not uploaded.

Your game never leaves this computer. The page does all the work in your browser and sends nothing anywhere. Game Boy and Game Boy Color games become a code; Advance games are too big to paste and become a folder instead.

  1. Copy the code

    The button works once a file is in.

  2. Paste it in the game

    • Back in game, type /mb setup if the window has closed.
    • Click the lower box in the setup window and press Ctrl+V. A big game can freeze the screen for a second or two while it arrives.
    • Click Play it now. The game is on the shelf immediately.

    The game stays on your shelf from then on, with its saves. MekkaBoy holds four pasted games at a time.

  1. Save the cartridge folder

    A Game Boy Advance game is too big to paste, so it becomes a folder of its own, saved as one zip file.

  2. Put it with your addons

    • Close the game.
    • Open the zip you just saved. Inside is one folder, MekkaBoy_Cart. Put it in Interface\AddOns next to the MekkaBoy folder, not inside it. If your unzipper wrapped it in a folder of its own, move it up one level: the .toc file must sit directly inside MekkaBoy_Cart….
    • Start the game again (a full start, not /reload) and type /mb cart, or pick the game from the shelf.

    The game keeps its saves with MekkaBoy. To take it off the shelf, delete its folder.

Read this first

Use a game you own. The code or folder is your copy of that game. Don't share it and don't ask other people for theirs.

We do not supply games and will not help you find them.

Sound and speed

A game you add this way has no sound. Sound needs a soundtrack pack recorded from your copy using the tools in the download; the FAQ explains how. If you skip that step, the game plays silently. The four included games have their music already.

If you want to know whether a game runs well before you go through this, check the Tested page. Game Boy, Game Boy Color and most cartridge types work; a few rare ones (camera, tilt sensor) do not. Heavy Advance games run slow.
